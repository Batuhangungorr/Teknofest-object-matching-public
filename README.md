# TEKNOFEST Object Matching

Tek bir referans görselinden yola çıkarak nesne eşleştirme yöntemlerini karşılaştırmak için geliştirilen bir Python değerlendirme projesi.

## Proje

- Tek referanslı nesne eşleştirme yöntemlerini ortak bir akışta karşılaştırmayı amaçlar.
- RGB ve termal görüntüleri aynı değerlendirme yaklaşımıyla ele alır.
- Farklı eşleştirme yöntemlerinin bağımsız olarak denenebilmesi için modüler bir yapı kullanır.
